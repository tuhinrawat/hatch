# Hatch

Hatch hides in your MacBook's notch and opens into your music (with live lyrics), one-click meeting joins, to-dos with reminders, a file tray and clipboard history.

**[Download the latest release](https://github.com/tuhinrawat/hatch/releases/latest)** · macOS 14+ · Apple silicon

This repository hosts Hatch's website and downloads. Early-access builds aren't notarized by Apple yet. After installing, open Hatch once, then go to **System Settings › Privacy & Security** and click **Open Anyway**.
